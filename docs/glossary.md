# 用語集

画面・メッセージ・メール文面で使う言葉の定義と使い方をまとめたものです。新しい画面や文言を作るとき、既存の文言を直すときは、まずここを確認します。

- 対象: 画面に表示する文言、エラー・完了メッセージ、メール・帳票の文面
- 「使う」に書いた言葉を使い、「使わない」に書いた言い方は避けます
- 用語を追加・変更するときは、この文書を先に更新します

最終更新: 2026-09-21

---

## 1. 取引先・人・組織

取引先は、取引の相手先を表す総称です。売る相手か買う相手かを区別する必要があるときだけ、得意先・仕入先を使います。

| 用語 | 意味 | 使い方 | 使わない |
|---|---|---|---|
| 取引先 | 取引相手の会社・団体の総称。得意先・仕入先・見込み客を含む | 種別を区別しない画面・項目(取引先マスタ、取引先名) | 顧客、お客様、客先 |
| 得意先 | 商品を売る相手 | 販売系の画面(見積・受注・売上・請求) | 顧客 |
| 仕入先 | 商品を買う相手 | 購買系の画面(発注・入荷・支払) | サプライヤー |
| 見込み客 | まだ取引が始まっていない取引先。商談の相手 | 商談管理 | — |
| 取引先担当者 | 取引先側の担当者(メールの宛先になる人) | 取引先担当者マスタ、メール送信の宛先 | 連絡先(担当者の意味で) |
| 自社担当者 | 自社側の担当者。ユーザーから選ぶ | 見積・受注・発注などの担当欄 | 社員、担当(単独) |
| 連絡先 | 電話・メール・FAXなど連絡手段の情報 | 担当者に持たせる情報の項目名 | 担当者の意味での使用 |
| ユーザー | システムにログインする人。ユーザーマスタの1件が1人 | ユーザー管理、ユーザーID | ユーザ、社員 |
| 従業員番号 | ユーザーを識別する番号。ログインに使う | ログイン画面、ユーザー管理 | 社員番号 |
| 部署 | 組織図の1つの単位 | 組織・部署マスタ、所属部署、申請部署 | 部門 |
| 組織 | 部署の階層全体(組織図) | 組織・部署マスタ、親組織 | — |
| ロール | 権限のまとまり。ユーザーに割り当てる | 役職・ロールマスタ | 役割(権限の意味で) |
| 担当 | 工程や役割を受け持つこと | 進捗確認の工程ごとの担当設定 | 担当者の意味での単独使用 |

## 2. 品目・在庫

品目は、取り扱う物すべての総称です。販売する商品だけでなく、原材料・部品・自由入力の明細項目も品目として扱います。

| 用語 | 意味 | 使い方 | 使わない |
|---|---|---|---|
| 品目 | 取り扱う物の総称(商品・原材料・部品など) | 明細の品目、品目名、品目コード、品目ID | 商品(総称の意味で)、アイテム、製品 |
| 品目構成 | 完成品(親)を構成する部品・原材料(子)と員数の定義 | 品目構成マスタ | 商品構成、部品構成 |
| 品目コード | 業務で決める品目のコード | 品目の登録・伝票の明細 | 商品コード |
| 品目マスタ | 品目を登録・管理するマスタ | 品目マスタ、品目単価マスタ、品目構成マスタ | 商品マスタ、商品単価マスタ、商品構成マスタ |
| 単位 | 数量の単位(PCS、KG、BOX など) | 単位マスタ、数量の隣の項目 | — |
| 倉庫 | 在庫を保管する建物・拠点 | 倉庫マスタ、倉庫の選択 | — |
| ロケーション | 倉庫の中の保管場所(棚・区画) | ロケーションマスタ、棚卸 | 保管場所、棚 |
| 入荷 | 仕入先から物が届くこと。入荷指示・入荷予定日・入荷実績で使う | 入荷、入荷指示、入荷予定日、入荷実績 | 受入 |
| 出荷 | 得意先へ物を送り出すこと。出荷指示・出荷予定日・出荷実績で使う | 出荷、出荷指示、出荷予定日、出荷実績 | — |
| 入庫 | 在庫が増える記録(入荷の実績が在庫に反映される) | 入庫、入庫履歴、入庫確定 | 入庫入荷実績(併記) |
| 出庫 | 在庫が減る記録(出荷の実績が在庫に反映される) | 出庫、出庫履歴、出庫確定 | 出庫出荷実績(併記) |
| 発注点/安全在庫 | 発注を促す在庫数量の基準と、切らさないための在庫数量 | 発注点/安全在庫マスタ | — |
| ロット | 同じ条件で製造・入荷した物のまとまり | 在庫のロット管理 | — |
| 品質区分 | 良品・検品待ち・破損品など、在庫の品質の区分 | 在庫、入庫 | — |

入荷・出荷は物流の出来事(指示・予定・実績)を指し、入庫・出庫は在庫の増減の記録を指します。実績履歴の画面では、入荷実績・出荷実績と、入庫・出庫の記録を別の項目として表示します。

## 3. 帳票・伝票

帳票は取引先などに渡す書類(PDF・メール添付)です。伝票は、システムに登録する業務データです。

| 用語 | 意味 | 使い方 | 使わない |
|---|---|---|---|
| 見積書 | 見積の内容を取引先に渡す帳票 | 見積書のPDF・メール送信・OTPダウンロード | — |
| 注文請書 | 受注の内容を取引先に渡す帳票 | 受注の帳票 | 受注書 |
| 納品書 | 出荷した内容を取引先に渡す帳票 | 出荷確定後に発行 | — |
| 売上関連書類 | 売上に紐づいて発行する書類の総称 | 売上管理の書類 | 売上伝票、売上書類 |
| 請求書 | 請求の内容を取引先に渡す帳票 | 請求管理 | — |
| 発注書 | 発注の内容を仕入先に渡す帳票 | 発注管理 | — |
| 検収書 | 入荷した物の検収結果を仕入先に渡す帳票 | 入荷の検収 | — |
| 出荷指示書 / 入荷指示書 | 外部倉庫などへ渡す指示の帳票 | 帳票(PDF)を指すとき | — |
| 出荷指示 / 入荷指示 | 出荷・入荷の指示のデータ | 指示の登録・取消 | — |
| 伝票 | 見積・受注・売上・発注・仕入・出荷・入荷など、登録する業務データの総称 | 一覧・検索の対象 | — |
| 仕訳 | 取引を借方・貸方で記録した会計データ | 仕訳データ出力、仕訳ルールマスタ、仕訳編集 | 振替 |
| OTP | ダウンロードのときにメールで届く確認コード(ワンタイムパスワード) | OTPダウンロード、OTPダウンロードログ | ワンタイムパス |

見積・受注・発注・請求などの語は、業務そのものや伝票を指すときに使います(見積管理、受注登録)。書類を指すときは「〜書」を付けます(見積書、請求書)。

## 4. 承認・状態

### 申請と承認

| 用語 | 意味 | 使い方 | 使わない |
|---|---|---|---|
| 申請 | 承認を求める操作 | 「承認を申請する」「申請しました」 | 提出する、提出しました |
| 承認申請 | 新規登録・変更・無効化の承認を求める申請の総称 | 承認申請中、承認申請の履歴 | 承認依頼 |
| 変更申請 | 承認済みのデータを変更するための申請 | 変更を申請する | — |
| 無効化申請 | データを無効にするための申請 | 無効化を申請する | — |
| 購買申請 | 発注のために社内で行う申請。承認申請とは別のもの | 購買申請、購買申請フォーム | — |
| 承認 | 申請を認める判定 | 承認する、承認済み | — |
| 差戻し | 承認者が申請を申請者へ戻すこと | 差戻し、差戻し理由、差戻し中 | 差し戻し、却下、否認 |
| 取下げ | 申請者が申請を引っ込めること | 取下げ、取下げ済み | 取下、取り下げ |
| 再申請 | 差戻し後に修正して申請し直すこと | 修正して再申請する | 再提出 |
| 仮登録 | 承認されるまで仮に登録した状態 | 承認機能が有効なマスタの新規登録 | — |
| 承認フロー | 承認の経路の定義 | 承認フロー定義 | ワークフロー(経路の意味で) |
| 決裁 | 承認者が判定を行うこと | 承認タスク(未処理・判定) | — |

### 状態の表示

| 種類 | 表示する言葉 | 説明 |
|---|---|---|
| 申請・伝票の状態 | 下書き / 仮登録 / 承認申請中 / 承認済み / 差戻し / 取下げ / 削除申請中 | 申請の進み具合を表す。「承認済」ではなく「承認済み」と書く |
| マスタの状態 | 有効 / 無効 | 使える状態か、使えない状態か。利用中・停止・取扱中・廃止などは使わない |
| 期限のあるデータ | 有効 / 期限切れ / 将来適用 | 適用期間があるデータ(単価、組織など) |
| 転記・送信の状態 | 未転記 / 転記済み / 転記失敗、送信待ち / 送信済み / 送信失敗 | 仕訳の転記、通知・メールの送信 |

状態の内部の値(active、suspended、APPROVED、CUSTOMER など)は画面に表示しません。

### 削除と無効化

| 用語 | 意味 | 使い方 |
|---|---|---|
| 削除 | データを消す。元に戻せない | 削除、削除しました。確認では「元に戻せません」と伝える |
| 無効化 | データを残したまま使えなくする | 無効化、無効化しました。戻すときは「有効化」 |
| 取消 | 出荷指示・入荷指示など、発行した指示を無かったことにする | 出荷指示の取消、入荷指示の取消 |

## 5. 操作

| 用語 | 意味 | 使い方 | 使わない |
|---|---|---|---|
| 登録 | データを新しく登録する | ボタンは「登録」、見出し・案内は「新規登録」 | 新規作成(登録の意味で) |
| 保存 | 編集した内容を確定する | ボタンは「保存」、結果は「保存しました」 | 更新(ボタンの名前として) |
| 作成 | ファイルや帳票、他のデータから新しいデータをつくる | PDFを作成、購買申請を作成、発注を作成 | 登録の意味での使用 |
| 削除 / 無効化 / 取消 | 4章のとおり | — | — |
| キャンセル | 入力を取りやめて閉じる | 入力を伴う画面・確認の取りやめ | フォームを閉じる |
| 閉じる | 参照だけの画面や表示を閉じる | 詳細の表示、完了メッセージ | — |
| 戻る | 別の画面へ戻る | 「一覧へ戻る」「ダッシュボードへ戻る」 | — |
| 検索 | 条件に合うデータを探す | ボタンは「検索」。条件は「絞り込み」と呼んでよい | — |
| 条件をクリア | 検索条件を空に戻す | 検索欄のボタン | リセット |
| すべて | 絞り込みで全部を選ぶ選択肢 | 「すべて」 | 全て、全部 |
| ダウンロード | 画面のデータをファイルで受け取る | 「CSVダウンロード」「PDFダウンロード」 | エクスポート、CSV出力(一般の画面) |
| CSVインポート | CSVファイルでデータを一括登録・更新する | 「CSVインポート」 | 取込、CSV取込、一括登録 |
| 出力 | 会計システムなど外部に渡すデータをつくる | 仕訳データ出力(画面名) | — |
| アップロード | ファイルをシステムに送る | 添付ファイル、画像のアップロード | — |
| メール送信 | メールを送る | メール送信、メール送信設定 | メール配信 |
| ログイン / ログアウト | システムに入る・出る | ログイン画面、ログアウト | サインイン |
| パスワード | ログインに使う秘密の文字列 | パスワード変更、パスワード再設定 | — |

## 7. 画面名

画面名はメニュー名を正とします。**画面の見出しは、メニュー名と同じ文字にします**(先頭に絵文字を付けてかまいません)。

### 画面名のつけ方
- マスタの画面は「〇〇マスタ」とします(「〜マスタ管理」「〜マスタ設定」としない)
- 設定の画面は「〇〇設定」、記録の画面は「〇〇ログ」とします
- 業務の画面は、次の一覧の名前をそのまま使います

## 8. 文言の書式

### メッセージ
| 種類 | 書き方 | 例 |
|---|---|---|
| 文体 | 「です・ます」体 | 保存しました |
| 完了 | 「〜しました」。1文の短いメッセージは句点を付けない。2文以上は文末に句点を付ける | 承認を申請しました |
| 失敗 | 「〜に失敗しました」。理由が分かるときは続けて示す。句点の付け方は完了と同じ | 保存に失敗しました |
| 確認 | 「〜しますか？」(全角の「？」)。元に戻せない操作は、あわせて「元に戻せません」と伝える | 削除しますか？ |
| 権限(閲覧) | 「この画面を閲覧する権限がありません」 | — |
| 権限(操作) | 「〇〇する権限がありません」 | 登録する権限がありません |
| 一覧が空 | 「該当するデータはありません」 | — |
| 参照先がない | 「〇〇が見つかりません」 | 取引先が見つかりません |
| 処理中 | 「〇〇中...」 | 読み込み中... |
| 承認機能の制限 | 「承認機能が有効な間は利用できません」 | — |

### 入力欄・選択肢
| 項目 | 書き方 |
|---|---|
| 必須の項目 | ラベルの末尾に「*」を付ける(例: 得意先 *) |
| 未選択の選択肢 | 「-- 〇〇を選択 --」(例: -- 担当者を選択 --) |
| 「すべて」の選択肢 | 「すべて」 |

### 記号
| 項目 | 書き方 |
|---|---|
| 三点リーダー | 半角の「...」 |
| 括弧 | 補足は半角の「( )」。前後に空白は入れない |
| 数字・英字 | 半角 |

### ID・コード・番号
| 用語 | 意味 | 例 |
|---|---|---|
| ID | システムが自動で付ける識別子。画面で変更できない | ユーザーID、品目ID |
| コード | 業務担当者が決める、業務上のコード。画面で入力する | 品目コード、取引先コード、勘定科目コード |
| 番号 | システムが採番する番号 | 見積番号、従業員番号 |

### アイコン(絵文字)
同じ操作には同じ絵文字を使います。

| 操作 | 絵文字 |
|---|---|
| ダウンロード | 📥 |
| CSVインポート | 📤 |
| メール送信 | ✉️ |
| 削除 | 🗑️ |
| 承認の申請 | 🚀 |

### ボタンの色
主要な操作(登録・保存・申請)はインディゴ、完了・確定・ダウンロードはエメラルド、削除など元に戻せない操作は赤にします。薄いグレーの文字は使いません(CLAUDE.md の「UIの文字色・視認性」に従う)。
