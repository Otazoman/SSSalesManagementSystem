# 承認タスク管理(未処理・判定)

[マニュアルの一覧](../README.md) > 申請・承認 > 承認タスク管理(未処理・判定)

あなたが承認する番になっている申請を、承認・差戻しします。

- **開き方**: メニューの **申請・承認** > **承認タスク管理(未処理・判定)**
- **対象**: 全員
- 一覧・検索・並び替え・CSV・承認の共通の操作は、[共通の操作](../basics/common-operations.md) を参照してください。

## 画面

![承認タスク管理](../images/workflow/approval-06-tasks-pending.png)

**承認待ちリクエスト一覧**に、あなたが今承認する申請が表示されます(右上に未決済の件数)。

| 列 | 内容 |
|---|---|
| 申請対象マスタ / コード | 申請された伝票・マスタの種類と番号 |
| 申請種別 / 申請者 | `REGISTER`(新規登録)・`UPDATE`(変更)・`DELETE`(削除)などの種類と、申請した人 |
| 現在の承認段階 | 何段目の承認か、申請日時 |
| 承認・差戻しコメント入力 | 承認・差戻しの理由などを書きます(差戻しの時は理由を書いてください) |
| 操作 | **承認**・**差戻し** |

## 承認する・差し戻す

1. **👁️ プレビュー** を押して、承認の経路(今どの段か)と申請の内容を確認します。

   ![申請の内容のプレビュー](../images/workflow/approval-07-tasks-preview.png)

2. 必要ならコメントを入力します。
3. **承認** または **差戻し** を押します。
   - 承認すると、次の段の承認者に回ります。最後の段の承認で確定し、伝票・マスタに反映されます。
   - 差し戻すと、申請者に戻ります。申請者は内容を直して再申請できます。

処理した申請は一覧から消えます。

![承認・差戻しをした後](../images/workflow/approval-08-tasks-after.png)

## まとめて承認・差戻しする

一覧の左端のチェックボックスで複数の申請を選び、上の **一括承認する**・**一括差戻しする** で、まとめて処理できます(コメントは全件に同じものが付きます)。

## 補足

- 承認依頼が届くと、メール(またはプロフィールで選んだ Slack)で通知されます。ダッシュボードの **あなたの承認待ち案件** にも表示されます。
- 承認の経路(誰がどの順に承認するか)は、システム管理者が [承認フロー定義](../admin/approval-flows.md) で設定します。
- 申請から承認までの流れの全体は、[申請から承認までの流れ](approval-flow.md) を参照してください。
