# メール送信設定

[マニュアルの一覧](../README.md) > 基本マスタ設定 > メール送信設定

帳票(見積書・請求書など)ごとに、メールの件名・本文・宛先と、帳票のテンプレートを設定します。帳票に使うフォント・ロゴ・印影もここでアップロードします。

- **開き方**: メニューの **基本マスタ設定** > **メール送信設定**
- **対象**: 管理者
- 一覧・検索・並び替え・CSV・承認の共通の操作は、[共通の操作](../basics/common-operations.md) を参照してください。

![メール送信設定](../images/admin/mail-settings-list.png)

## 帳票共通アセット(フォント・ロゴ・印影)

**1. 日本語共通フォント(.ttf)**・**2. 会社ロゴ画像(.png)**・**3. 社印・角印・丸印(.png)** をアップロードします。すべての帳票で使います。ロゴ・印影は背景が透明な PNG をおすすめします。

## 帳票ごとの設定

左の **対象帳票の選択** で帳票を選び、右で設定します。

| 項目 | 内容 |
|---|---|
| 帳票Excelテンプレート(.xlsx) | 帳票のレイアウトを Excel で作ってアップロードできます(アップロードしない場合は既定のレイアウト)。**ストレージ内を参照** でアップロード済みのファイルを確認できます |
| 送信元メールアドレス(FROM) | 未設定の場合は、会社・システム設定の送信元を使います |
| 常時Cc・常時Bcc | 必ず写しを送る宛先 |
| 帳票PDFのファイル名プレフィックス | 「プレフィックス_伝票番号.pdf」のファイル名になります |
| メール送信件名テンプレート *・メール本文テンプレート * | 画面の下の **差し込み可能プレースホルダー** を使うと、取引先名・伝票番号などが自動で入ります |

- Excel テンプレートで使えるプレースホルダーは、[帳票テンプレートのサンプル](../../../samplereport/README.md) を参照してください。
