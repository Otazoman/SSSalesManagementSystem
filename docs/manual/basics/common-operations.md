# 共通の操作(一覧・検索・登録・CSV・承認)

[マニュアルの一覧](../README.md) > はじめに > 共通の操作

マスタや伝票の画面は、ほぼ同じ操作で使えます。ここでは、取引先マスタを例に説明します。

![取引先マスタの一覧](../images/master/partners-list.png)

## 一覧を見る・探す

| 操作 | 方法 |
|---|---|
| 状態で絞り込む | 一覧の上のタブ(**有効**・**仮登録**・**無効**・**すべて**)を選びます。**該当件数**に、条件に合う件数が表示されます |
| 条件で探す | **絞り込み検索**の欄に、コード・名前などを入力します。名前は**部分**一致(一部が合えばよい)と**完全**一致(全部が同じ)を選べます。**条件をクリア**で元に戻ります |
| 並び替える | 一覧の列の見出しを押すと、その列で並び替えます。もう一度押すと逆順になります。**Shift キーを押しながら**見出しを押すと、複数の列で並び替えられます(先に押した列が優先) |
| ページを移る | 件数が多い場合は、一覧の下のページ番号で移動します(表示する件数も選べます) |

### 状態の意味

| 状態 | 意味 |
|---|---|
| 有効 | 使える状態。伝票などで選べます |
| 仮登録 | 登録の承認を待っている状態(承認機能を使っている場合)。承認されると有効になります |
| 無効 | 使わなくなった状態。伝票などでは選べませんが、過去の伝票の表示には使われます |

## 登録する

1. **➕ 新規個別登録・CSVインポート** を押します。一覧の上に、登録の欄が開きます。
2. 左側の **新規個別〇〇登録** に入力して、**登録** を押します。
   - `*` の付いた項目は必須です。
   - コードの欄を空にすると、自動で番号を付けます(画面によっては必須です)。
3. 閉じる時は **キャンセル** を押します。

![取引先の登録の欄](../images/master/partners-form.png)

## 変更する・無効にする

一覧の右の **操作** 列から行います。

| 操作 | 内容 |
|---|---|
| 変更 | 登録の欄に今の内容が表示されるので、直して保存します |
| 無効化 | 使わなくなったデータを無効にします(削除はしません)。無効にしたデータは **無効** タブで確認できます |

## CSV で一括登録する(CSV インポート)

1. **➕ 新規個別登録・CSVインポート** を押します。
2. 右側の **〇〇CSV一括インポート** に、CSV の1行目(見出し)の形が表示されます。この形の CSV を用意します。
3. **〇〇CSVファイルを選択** を押して、CSV を選びます。取り込みが始まり、結果が表示されます。

- CSV は UTF-8 で保存してください(Excel では「CSV UTF-8(コンマ区切り)」)。
- 同じコードの行は更新、新しいコードの行は追加になります。
- **承認機能を有効にしている画面では、CSV インポートは使えません**(ボタンが押せなくなります)。承認を通さずにデータが登録されるのを防ぐためです。
- 各画面の CSV の見本は、`sampledata/` フォルダにあります([サンプルデータ](../../../sampledata/README.md))。

## CSV で一覧を出力する(CSV ダウンロード)

画面右上の **📥 CSVダウンロード** を押すと、一覧を CSV で保存できます。出力した CSV は、そのまま CSV インポートにも使えます。

## 承認機能を使う場合

会社・システム設定で承認機能を有効にした画面では、登録・変更が「申請」になります。

1. 登録・変更すると、**仮登録/申請中** になり、承認者に通知が届きます。
2. 承認者が **承認タスク管理** で承認すると、**有効** になります(承認の段が複数ある場合は、すべての段の承認が必要です)。
3. 差し戻された場合は、ダッシュボードの **あなたの申請** や **申請履歴・進捗一覧** から開いて、直して再申請します。

承認の操作は、申請・承認のマニュアルを参照してください。

## 添付ファイル・外部リンク

取引先・品目・倉庫などには、ファイル(PDF・画像など)や、共有フォルダなどのリンクを添付できます。

- **ファイル添付**(または **Choose File**)でファイルを選びます。
- リンクは、名前と URL を入力して **追加** を押します。
